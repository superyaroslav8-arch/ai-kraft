# Ai-craft

**Создание сайтов по описанию с помощью искусственного интеллекта и создание доменов и ссылок для сайтов — полностью бесплатно.**

- **Репозиторий:** https://github.com/superyaroslav8-arch/ai-kraft  
- **Сайт:** https://superyaroslav8-arch.github.io/ai-kraft/  
- **Vercel:** https://ai-kraft-superyaroslav8-archs-projects.vercel.app

## Что работает (бесплатно для всех)

1. Вход без пароля  
2. Сайт по текстовому описанию  
3. Выбор адреса (поддомен или свой домен)  
4. Открыть готовый сайт  
5. Короткие ссылки  
6. Фото по описанию (AI)  
7. Помощник Нейро  
8. Тема и язык

Платить ничего не нужно — ни вам, ни пользователям.
